# 8.1.3 Worktree and Ownership Freeze

All write branches fork from the Wave 0 schema-freeze commit. Children must not spawn children. The integration parent owns cross-stream contract changes, merge order, controller integration, release metadata, and final verification.

| Lane | Branch / worktree suffix | Exclusive write scope | Forbidden scope |
| --- | --- | --- | --- |
| A Config/Migration | `patch/8.1.3-config-migration` / `8.1.3-config-migration` | config helper; private historical decoding inside the current bridge migration; current receipt; named migration tests | controller, Swift, secrets, versions/docs; no legacy-only directory or runtime |
| C Registry/Catalog | `patch/8.1.3-provider-registry` / `8.1.3-provider-registry` | new registry/credential/route/catalog modules; LB env/catalog; OpenRouter secret store; named tests | bridge, controller, capability, CLI/Swift |

## Shared-File Protocol

- A child that discovers a required edit outside its lease reports it; it does not edit the file.
- Public contract changes return to the parent before implementation continues.
- Test fixtures live with the module owner unless they are cross-stream v3 facades, which remain parent-owned.
- Each write lane commits its bounded changes and reports commit SHA, changed files, tests, remaining blockers, and any requested parent integration.
- No lane may resolve a merge conflict by deleting another lane's behavior or weakening a test.
