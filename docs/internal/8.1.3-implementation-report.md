## Release decision

**SOURCE COMPLETE / RELEASE BLOCKED.** The 8.1.3 implementation is integrated
and its current local source corpus is green. This report is not release
authorization: trusted physical macOS/provider evidence, the final main/tag
binding, npm maintainer authentication, and explicit stage/publish authority
remain absent. Historical receipts are never reused for the release commit.

## Evidence status legend

- **passed-hermetic** — a local source/build/test/gate check passed without
  proving a user environment. Exact-commit release receipts must still be
  regenerated from the clean release candidate; earlier SHA-bound receipts
  are historical only.
- **not-run-real** — requires a redacted, target-bound real-environment
  artifact. Fixtures, source inspection, a configured credential, and process
  status cannot satisfy it.
- **blocked-external** — needs an authorized external action or authority
  outside this checkout, such as a real target environment, a GitHub
  main/tag operation, npm-owner authentication, or human 2FA approval.

A row can carry more than one label. For example, a WebSocket fixture can be
`passed-hermetic` while the live WebSocket requirement remains
`not-run-real`. None of these labels is shorthand for a release-ready source
state.

## Explicit user override: legacy paths

The user explicitly overrides the work order's former one-release compatibility
proposal in §10.3. Active legacy runtime paths and public command aliases are
deleted for 8.1.3:

- `sks codex-lb …` must return `unknown_command`; it is not deprecated,
  forwarded, or aliased.
- Legacy Desktop/provider modes are not active runtime choices.
- Historical SKS-owned markers may be parsed only inside the private,
  receipt-backed migration path. That parser is migration input, not a
  runnable legacy runtime or compatibility alias.

This override supersedes the old alias mapping in the work order. The
`router-codex-lb-removed` fixture is the hermetic command-surface evidence;
it does not prove an installed package until the final package proof is
regenerated.
