## Architecture result

- Managed runtime: one local `desktop-bridge` runtime for managed Desktop and
  CLI routing.
- Provider profiles: Codex-LB and OpenRouter coexist, with independent
  credentials, endpoint policy, catalog state, and capability scope.
- Routing: combined catalog plus explicit route index; fallback is always
  `none`; model-name heuristics are not a route authority.
- Identity: ChatGPT OAuth stays Codex-owned and is stripped from provider-bound
  upstream requests.
- Migration: current migration privately recognizes historical SKS-owned
  values, writes a redacted receipt, and does not create or activate a legacy
  runtime directory.
- Rollback: receipt-based metadata rollback preserves newer OAuth and
  credentials.
- Capacity: a persisted 1000 preference is runtime-normalized to 256 children
  / 257 total without rewriting it; explicit CLI over-cap values are rejected.
